How the simulation maps to the robot

Plant: bicycle model at base_link (centre of the fixed axle), θ' = v·tan(δc)/a with a = steer_axle_x. The left wheel angle is converted to the centre angle with 1/tan(δc) = 1/tan(δL) + W/(2a). The steering actuator follows the command with a first-order lag and its own rate limit, plus an optional calibration offset.

Controller: runs at the controller rate, prunes the path, resamples it, computes curvature, picks the speed with the same three cases and near-goal slowdown as control(), then solves the MPC with the ADMM solver and sends the left wheel angle. The final in-place rotation (rotateCarLike) is not simulated, as with ignore_last_rotate: true.

Localization noise and the pose jump only affect the pose the controller sees. Error charts use the true pose.
